# Залипни

Статический сайт с мини-играми, тестами и спрятанными секретами для аудитории 14–25 лет.
Чистые HTML, CSS и JavaScript: без фреймворков, сборки, сервера и базы данных.

## Что внутри

- `index.html` — главная с плитками всех разделов
- `riddle.html`, `quiz.html`, `excuse.html`, `meme.html`, `reaction.html`, `emoji.html` — игры, тест и генераторы
- `secrets.html`, `room.html`, `psst.html` — пасхалки, тайная комната и тайная страница
- `about.html`, `contacts.html`, `privacy.html`, `404.html` — служебные страницы
- `config.js` — **все настройки**: название, адрес сайта, Telegram, почта, реклама, Метрика
- `js/secrets.js` — список пасхалок (id, подсказка, условие)
- `js/data-*.js` — тексты: загадки, оправдания, мемы, вопросы теста, эмодзи-загадки
- `css/style.css` — оформление, `fonts/` — шрифты, `img/` — иконки и картинка для превью

## Как поменять настройки

Открой `config.js` и замени текст в кавычках:

- `SITE_URL` — адрес сайта, когда появится домен (например, `'https://example.ru'`)
- `TG_URL` — ссылка на Telegram-канал (кнопки «Предложить идею» оживут сами)
- `EMAIL` и `OPERATOR` — почта и владелец сайта для «Контактов» и «Политики конфиденциальности»
- `RSYA_ENABLED` — реклама РСЯ, по умолчанию `false`; блоки указываются в `RSYA_BLOCKS`
- `METRIKA_ID` — номер счётчика Яндекс Метрики (пусто = Метрика не подключена)

## Публикация

Сайт публикуется на GitHub Pages автоматически при каждом изменении в ветке `main`
(`.github/workflows/deploy.yml`). Во время публикации `tools/set-site-url.js` подставляет адрес сайта
вместо `__SITE_URL__` в превью ссылок, `sitemap.xml` и `robots.txt`. Если `SITE_URL` пустой,
берётся адрес GitHub Pages.

В настройках репозитория: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Посмотреть у себя

Открой `index.html` двойным щелчком — сайт работает прямо с диска.
